# 变更记录

> 版本号跟着前端功能走（不是 git tag）。更细的逐条改动看 `git log`；这里只记"这一版对外变了什么"。

- **v7.6（2026-11-08）**：
  - 流式对话由 GET 改 **POST**（`POST /chat/ask-stream` + JSON body），问题不再拼进 URL，避免超长与访问日志泄露
  - 确认弹窗 404/409 分支补 `stopCountdown()`，失败后倒计时不再继续跑
  - 文档整理：README 瘦身，新增 `docs/部署.md`、`docs/待办.md`、本文件
- **v7.5（2026-11-05）**：
  - 任务/记忆管理从设置页迁到聊天侧边栏：新增「会话 / 任务」双 tab，任务支持状态筛选、完成、删除与来源会话跳转
  - 记忆按会话分组：会话行显示本会话记忆条数，展开后直接管理；全局记忆固定在会话列表上方
  - 移除 `localStorage.currentSessionId` 跨页同步，设置页不再维护第二套任务/记忆状态，减少跨页面/跨设备串数据
  - 新增应用内到期提醒：`utils/dueTasks.js` + `tests/dueTasks.test.js`（4 个用例），页面可见时每 30 秒轮询 `/user/tasks/due`，10 分钟窗口内到期任务弹 `ElNotification`，按 `taskId + dueAt` 去重
  - 确认弹窗性能优化：去掉全屏 `backdrop-filter`、面板入场动画 0.28s → 0.18s、支持 `prefers-reduced-motion`；确认/取消成功后关闭等待从 1200ms/900ms 降到 450ms/300ms
  - 确认成功后展示后端 `ConfirmResult.receipt`（人设化回执），不再硬编码文案；侧栏任务/记忆刷新推迟到 `requestIdleCallback`（600ms 超时兜底）
  - 新增 `utils/sidebar.js` + 6 个纯函数单测；前端测试总数 41；会话删除确认文案补充“本会话记忆”
- **v7.4（2026-11-05）**：
  - 登录页视觉重构：玻璃拟态卡片 + 背景光斑、步骤切换左右滑动过渡、密码规则改为 4-32 位字母/数字/下划线
  - 新用户判定改为 `/user/me` 返回的 `isNewUser` 字段，移除独立 `/user/is-new-user` 调用；503 短信服务不可用引导改用密码登录，60s 冷却仅在后端 400"频繁"时启动
  - 历史页视觉重构：卡片化 + motion-v 入场动画 + 模型标签 + 删除时级联清理本地 `currentSessionId`
  - `getMemories` 增加 `sessionId` 参数（P1.3 会话隔离），设置页记忆面板带当前会话 id，只显示「全局 + 当前会话」的记忆
  - `request.js` 新增 `503` 错误文案（短信服务不可用）；`ChatView` 维护 `localStorage.currentSessionId` 供设置页使用
- **v7.3（2026-11-04）**：
  - `api/user.js` 补全 MindButler P1 接口：任务 CRUD（`/user/tasks`，到期待办、游标分页、乐观锁完成/删除）、记忆 CRUD（`/user/memories`）、待确认动作（`/user/pending-actions` current / get / confirm / reject）
  - 设置页新增「MindButler · 记忆与任务」卡片：任务列表（待办/已完成/已取消过滤、完成、删除）+ 记忆列表（删除）；完成任务走乐观锁（409 时拉单条任务拿最新 version 重试）
  - `TaskConfirmDialog` 补全记忆条目渲染（key 标签、值、会话/全局 scope、长期/动态 memType，v7.4 兼容 `sessionId` 旧字段）；`parseLocalDateTime` 手动解析无时区 LocalDateTime，设置页任务日期避免 8 小时偏移
- **v7.2（2026-11-03）**：
  - 聊天触发任务：解析 `/chat/ask-stream` 文案尾部的 `[[MB:pending=N]]`，SSE 结束后自动打开任务确认弹窗
  - `TaskConfirmDialog`：任务/记忆混合确认、倒计时、过期/已处理状态、确认/取消/稍后处理，移动端底部抽屉
  - 刷新/切回会话调用 `/user/pending-actions/current` 恢复未处理提案；弹窗打开时禁用输入，收起后保留“去确认”提醒条
  - `utils/pending.js` + 10 个纯函数测试；历史/复制/导出展示前统一剥离机器标记
- **v5.2（2026-10-28）**：
  - 设计系统：LobeChat 风格双主题（`design.css` + `useTheme` + Element Plus 变量映射）
  - 组件拆分：`ChatView` 拆出 `ChatSidebar` / `ChatMessage` / `ChatComposer` / `StreamingMarkdown` / `WelcomeScreen`
  - 打字机引擎：`useTypewriter`（stable + frontier 两级渲染）+ `fence.js`（围栏平衡检测）
  - 代码高亮：`highlight.js` 按需注册 18 种语言，代码块带语言标签
  - 流式 Markdown：`renderStreamingMarkdown` 未闭合围栏补临时闭合符，避免代码块闪烁
  - 侧边栏搜索、主题切换、消息模型标签、`409` 会话模型冲突处理
  - 新增 21 个单元测试（sse / fence / highlight）
  - `vite.config.js` 加 `manualChunks` 分包 + SSE 代理配置
- **v5.1（2026-10-26）**：模型选择、历史游标分页、8000 字输入限制、顶部工具栏（历史/设置/导出/登出）、业务错误交由页面处理
- **v5.0（2026-10-17）**：SSE 解析器独立成 `utils/sse.js`，支持前导空格保留与 CRLF 兼容
- **v4.0（2026-09-26）**：登录系统重构（验证码 + 密码双模式）、token 独立存储、聊天接口路径统一为 `/chat/*`
